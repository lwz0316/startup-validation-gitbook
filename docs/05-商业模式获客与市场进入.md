# 第 5 章：商业模式、获客与市场进入

## 5.1 商业模式的基本问题

商业模式不是“我们以后收会员费”一句话，而是一组需要验证的机制：谁付费、为什么付费、付多少、多久付一次、交付成本是多少、通过什么渠道获得客户、谁负责续费。

## 5.2 价格不是成本加成

早期定价可以从客户获得的价值、替代方案成本、预算和购买风险出发。不要因为产品还不成熟就默认免费；免费用户的行为通常不能代表付费需求。可以用探索性报价、付费试点、押金、预售或服务费测试支付意愿。

## 5.3 获客与销售漏斗

把获客拆成可测步骤：触达 → 回复 → 诊断 → 演示/试用 → 试点 → 付费 → 续费/转介绍。每一步都记录数量、转化率、周期和成本。

B2B 场景要额外记录：使用者、经济购买者、批准者、实施者和阻碍者。不要只跟最喜欢产品的人沟通。

## 5.4 市场进入策略

早期市场进入应尽量集中：一个客户类型、一个场景、一个主要渠道、一个可复用案例。渠道选择取决于客户在哪里获得信任，而不是创业者觉得哪个渠道“流量大”。

## 5.5 单位经济模型

至少估算：平均收入、毛利、交付成本、获客成本、销售周期、回本周期、留存和扩张收入。早期数字可以是范围，但必须标明来源和置信度。
