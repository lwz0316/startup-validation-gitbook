# 课程地图与入学诊断

## 课程主线

MIT 15.390 的核心不是“如何想出一个好点子”，而是如何把一个模糊机会逐步变成可验证的技术型新企业：

> 机会识别 → 市场量化 → 客户研究 → 价值主张 → 竞争定位 → 商业模式 → 产品开发 → 市场进入 → 财务计划 → 融资与启动

每一步都可能推翻前一步。好的创业过程不是把最初的计划坚持到底，而是用证据尽快发现错误，并用较低成本调整方向。

## 入学诊断

请给每题打 0—2 分：0 = 完全没有，1 = 有初步想法，2 = 已有证据或经验。

1. 我能用一句话说清楚目标客户是谁。
2. 我观察过客户最近一次如何处理这个问题。
3. 我有至少 5 次相关客户访谈或观察记录。
4. 我能说出客户现在使用的替代方案。
5. 我知道客户为什么愿意改变现状。
6. 我能估算一个早期可进入市场，而不是只说“所有人”。
7. 我有一个可在两周内制作的最小原型。
8. 我知道收入来自谁、何时产生、如何收取。
9. 我估算过每位客户的获客成本和交付成本。
10. 我知道最可能让项目失败的三个风险。

总分解释：

- 0—6 分：从第 1 章开始，不要急着写商业计划。
- 7—14 分：可以边验证边学习，优先完成访谈和市场定位。
- 15—20 分：进入项目冲刺阶段，用课程帮助你补齐商业模式和财务证据。

## 贯穿项目设定

选择一个真实但风险可控的项目。它可以是一个创业想法、现有业务的新产品、个人服务，或一个内部效率工具。不要选择涉及重大资金、医疗诊断、法律结论或用户隐私的项目作为第一个练习。

写下：

- 项目暂定名：
- 我想解决的具体问题：
- 我猜测的第一类客户：
- 客户现在怎么解决：
- 我最不确定的三件事：
- 两周内可以验证什么：

## 本章产出

完成一页《项目假设卡》，至少包括：目标客户、问题、现有替代方案、初步价值、最危险假设和下一步验证动作。
